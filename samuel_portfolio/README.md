# Samuel's Software Engineering Portfolio

A responsive portfolio website for presenting my software engineering interests, skills, projects, and contact information.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Sections
- Introduction and availability
- About
- Skills and tools
- Selected projects
- Learning principles
- Contact links

## Run locally
No build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

For live reload during development, use the Live Server extension in VS Code.

## Before publishing
Update the placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- LinkedIn profile URL
- Project repository/demo links
- Confirm that every listed skill and project feature accurately reflects your work.

## Deploy
This is a static website and can be deployed with GitHub Pages, Netlify, or Vercel.

### GitHub Pages
1. Push these files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under build and deployment, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for the deployment to finish and open the published URL.
